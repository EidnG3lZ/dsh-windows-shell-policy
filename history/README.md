| 载体 | 内容 | 何时读 |
| --- | --- | --- |
| [CHANGELOG.md](../CHANGELOG.md) | 每个版本的对外变更（`0.0.1` → `0.1.1`，含破坏性变更、修复与原因） | 追溯"某能力/某修复是哪个版本引入的" |

| git 历史 | 提交信息含详细中文说明（如 `8e7c580`、`80f3732`、`75a8918`、`3e4bdcf`） | 追溯具体改动与时间线 |
| [DECISIONS.md](../DECISIONS.md) / [RISKS.md](../RISKS.md) | 决策与风险**当前有效**的状态（不是历史流水） | 涉及选择或风险时 |

## 归档约定（什么时候才动这个目录）

1. 当某份当前状态文档（如 [NOW.md](../NOW.md)）里的**过程性内容**被新快照取代、但仍有追溯价值时，把旧内容**移动**到这里，并在原处留一行链接（不复制两份）。
2. 不要把所有变更都往这里倒——版本对外变更归 [CHANGELOG.md](../CHANGELOG.md)，设计理由归 [DECISIONS.md](../DECISIONS.md)，过程记录归 [docs/roadmap-composition.md](../docs/roadmap-composition.md)。
3. 不保存完整聊天记录与操作流水账。
